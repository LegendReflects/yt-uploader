Privacy policy

Last updated: 10 November 2026

yt-uploader is a personal tool used only by its owner, on the owner's own YouTube channels.

  • It uses the YouTube Data API and YouTube Analytics API to upload and schedule the owner's videos, update their details, and read the owner's channel statistics.
  • Sign-in tokens are kept only on the owner's own computer. No data is sent to any server other than Google's.
  • No personal data from other people is collected, stored, sold or shared.
  • Access can be removed at any time at myaccount.google.com/permissions.

yt-uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
